# BZ Hub 发布指南

本文覆盖 GitHub 源码仓库、Wallpaper Engine 创意工坊以及演示视频的发布流程。发布前先使用测试数据，隐藏邮箱、API Key、本机路径和真实日程。

## GitHub 发布检查

1. 确认 `.env`、`src-tauri/target/`、`dist/`、日志和本地 QA 截图没有被 Git 跟踪。
2. 运行完整验证：

   ```powershell
   pnpm build
   node wallpaper-engine/check.mjs
   cd src-tauri
   cargo test
   ```

3. 检查 Git 变更和敏感信息，再提交源码。
4. 使用 GitHub Releases 分发 Windows 可执行文件、安装包或 macOS 构建产物，不要把编译产物直接提交到源码历史。
5. 发布公开仓库前选择并添加明确的开源许可证；没有许可证时，源码虽然可见，但默认不代表允许他人复制或再分发。

建议仓库描述：

> A local-first cross-platform launcher with calendar, weather, optional sync, AI control and a Wallpaper Engine companion.

建议主题标签：`tauri`、`react`、`rust`、`launcher`、`productivity`、`supabase`、`wallpaper-engine`。

## Wallpaper Engine 创意工坊

### 发布前测试

- 在 16:9 和 21:9 显示比例下检查裁切、水面范围和粒子效果。
- 关闭 BZ Hub 后重载壁纸，确认它仍按系统时间正常运行。
- 分别测试自动、清晨、白天、黄昏、夜晚，以及晴、雾、雨、雪和雷阵雨选项。
- 测试暂停、恢复、静音、0% 和 25% 音量。
- 检查素材与代码全部位于项目目录，不依赖互联网资源。
- 确认预览图不包含个人信息，并适合全年龄查看。

### 发布操作

1. 在 Wallpaper Engine 中用 `wallpaper-engine/bz-hub-landscape/index.html` 创建或打开 Web Wallpaper。
2. 点击编辑器顶部“创意工坊 → 准备发布”。
3. 填写标题、说明、类型、内容分级和可见性。
4. 导入静态预览图，或按 `G` 录制方形 GIF；GIF 建议 128×128、低于 500 KB，硬性上限 1 MB。
5. 点击“发布”。以后从同一个本地 WE 项目再次发布即可更新原条目。

Wallpaper Engine 不会把项目文件当作备份。请同时保留仓库和 `wallpaper_engine/projects/myprojects` 中的实际项目目录。

### 推荐标题

中文：`BZ Hub · 山谷气象 | 动态天气与时间`

英文：`BZ Hub Valley Weather | Dynamic Time & Weather`

### 推荐说明

```text
一款安静的超宽屏山谷动态壁纸，包含清晨、白天、黄昏、夜晚、雾、分级雨雪、雷雨、水面流动与本地合成环境声。

```

## 演示视频

推荐先制作一条 75～90 秒横屏主视频，再按相同素材单独剪一条 30～45 秒竖屏版本。不要直接裁切横屏成竖屏，否则入口卡片和设置文字会过小。

### 录制准备

- 使用一份专门的演示数据，入口名称与图标整齐，不显示私人路径。
- 暂时退出聊天、邮箱和其他可能弹出通知的软件。
- 将 Windows 缩放和录屏分辨率固定，推荐 1920×1080、60 FPS。
- 可使用 OBS Studio；只录应用窗口时检查托盘、系统选择器和 Wallpaper Engine 是否也需要单独录制。
- 若展示跨设备同步，准备 Windows 与 Mac 两段独立画面，后期并排。

### 90 秒分镜

| 时间 | 画面 | 旁白重点 |
| --- | --- | --- |
| 0–5 秒 | 桌面与托盘，一次点击打开 BZ Hub | “把常用网页、程序和项目收进一个入口。” |
| 5–18 秒 | 四列卡片、分类、收藏、拖动与拼音搜索 | 常用内容一屏到达 |
| 18–30 秒 | 打开单入口，再展开组合入口并顺序启动 | 参数、延迟和子目标开关 |
| 30–42 秒 | 日历页面，新建重要事项，返回首页查看倒计时 | 日程与节假日 |
| 42–52 秒 | 天气详情与保持唤醒开关 | 轻量桌面信息与系统能力 |
| 52–63 秒 | 在 AI 对话中让 BZ Hub 打开入口、添加日程 | AI 操作应用，而不是改代码 |
| 63–78 秒 | Wallpaper Engine 在晴、雨、雪和夜晚间切换 | 独立属性与真实天气联动 |
| 78–90 秒 | Windows/macOS、GitHub 与创意工坊地址 | 开源、下载与关注引导 |

### 后期与导出

- 对点击位置做轻微放大，重要操作增加短字幕；不要让鼠标轨迹过快。
- 删除加载等待，只保留能说明状态变化的 0.5～1 秒停顿。
- 背景音乐应低于旁白，且确认拥有平台发布权；也可以只用壁纸自身环境声。
- 横屏导出建议 H.264、1080p、60 FPS、15～25 Mbps；竖屏使用 1080×1920。
- 发布前逐帧检查邮箱、令牌、API Host/Key、文件路径和浏览器标签页。
