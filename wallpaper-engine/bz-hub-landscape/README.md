# BZ Hub · 山谷气象动态桌面

这是一个 Wallpaper Engine Web Wallpaper 项目。它包含清晨、晴天、黄昏、夜晚、阴雾、下雨和下雪七种风景状态：时间和天气决定当前图片，每次只显示一张背景，直接切换，不交叉叠加。雨雪与飘絮是独立粒子。

## 导入

1. 打开 Wallpaper Engine 编辑器，把本目录中的 `index.html` 拖到“创建壁纸”。
2. Wallpaper Engine 会把项目复制到自己的 `wallpaper_engine/projects/myprojects/` 目录；之后请在 BZ Hub 设置中选择这个“复制后的项目文件夹”，而不是只选择仓库目录。
3. 在 BZ Hub 的“设置 → 动态桌面”中选择 Wallpaper Engine 的 `launcher.exe`，选择复制后的项目文件夹，然后点击“连接并打开”。

`bridge.json` 和 `bridge.js` 由 BZ Hub 自动写入，里面只有本机 `127.0.0.1` 天气桥接地址，不包含和风天气 API Key。壁纸每 2 秒读取本机状态，每 20 秒刷新桥接地址；这些轮询不会请求天气服务，不额外消耗天气 API 额度。

## 独立使用与壁纸属性

壁纸不依赖 BZ Hub 也可以使用。在 Wallpaper Engine 的“已安装”页面选中壁纸后，可在右侧属性中调整：

- **时间场景**：自动跟随 BZ Hub 模拟时间或本机系统时间，也可以固定为清晨、白天、黄昏或夜晚。
- **天气场景**：自动接收 BZ Hub 天气；未连接时显示晴朗场景。也可以固定为晴朗、雾、三级雨、雷阵雨或三级雪。
- **环境声音 / 环境音量**：独立开关并调整本地合成的风、溪流和降雨声。

手动选择的时间或天气优先于 BZ Hub 联动；切回“自动”即可恢复联动。属性带简体中文和英文文本。

## 发布到 Steam 创意工坊

1. 先在 BZ Hub 关闭模拟，再完全退出 BZ Hub，确认壁纸仍会随本机时间运行。
2. 在 Wallpaper Engine 中依次测试所有时间、天气和声音属性。
3. 打开编辑器顶部“创意工坊”，选择“准备发布”，设置标题、说明、分类、内容分级与可见性。
4. 制作全年龄预览图或不超过 1 MB 的方形 GIF，然后发布。

Wallpaper Engine 不会替你备份项目。发布前保留本目录以及 WE `projects/myprojects` 中实际项目目录的副本；以后应从同一个 WE 项目更新，避免创建重复的创意工坊条目。可直接使用的中英文说明与完整检查清单见 [`docs/PUBLISHING.md`](../../docs/PUBLISHING.md)。

## 更新已有壁纸

将本目录的新文件复制到 Wallpaper Engine 实际使用的项目文件夹，包括 `assets`、`scene-model.js`、`water-regions.js`、`renderer.js`、`ambient-audio.js`、`wallpaper.js`、`styles.css` 和 `index.html`，然后在 BZ Hub 中重新“连接并打开”。仅更新仓库不会更新 WE 导入时复制的文件。也可以直接重新导入整个项目并重新选择目录。

这次新增了 `project.json` 中的声音属性。已有项目请将 `general.properties` 内的 `ambientsound`、`ambientvolume` 两项合并到自己的项目配置，保留原来的其他属性与项目标识；也可在 WE 编辑器“编辑 → 更改项目设置”添加对应属性。不要直接覆盖已有项目的整个 `project.json`。

## 尺寸与素材

七张背景均为 **3440×1440**。使用内置 imagegen 对现有图片做左右 AI 扩图，每种状态一版，共七次。生成器实际输出约 1939×811，再以本地 Lanczos 等比缩放导出到准确目标尺寸；不到 0.2% 的比例差通过居中边缘裁切消除。因此这是 AI 扩图加本地放大，不是原生 3440×1440 细节的生成图。

原始素材保存在上一级 `original-assets/`；扩图提示词、来源和尺寸记录在上一级 `asset-generation.json`。最终壁纸只使用本目录的 `assets/`，不依赖生成器输出目录。其他屏幕比例使用等比铺满并裁边，不拉伸。

## 动态与模拟

- 水面：沿河岸描绘覆盖区域，排除主要石块，覆盖远处河道到近景。使用向下游移动的多尺度噪声折射和细微反光变化，替代横向整条扭动。山体、树冠与岸边保持固定；轮廓可在 `water-regions.js` 中调整。
- 降雨：小雨、中雨、大雨、暴雨按天气代码及降水量改变密度、速度、长度；雨滴垂直落下，并在河道范围内产生涟漪。
- 降雪：小雪、大雪、暴雪改变雪花密度和下落速度；雪花仅保留缓慢的自然漂移。
- 暂停风速驱动的所有效果，保留晴天和雾天缓慢下落的飘絮、雾层；雷阵雨带低强度间歇闪光。
- 默认 30 FPS，接收 Wallpaper Engine 的全局帧率与暂停设置。主画面最多 3440×1440，雨雪使用较小画布；系统“减少动画”启用时停止这些运动。WebGL 不可用时保留静态背景及雨雪、飘絮和雾，水面扰动停用。
- 在 BZ Hub“设置 → 动态桌面”打开“启用天气联动”和“模拟桌面天气与时间”。可固定时刻、选择天气。约 2 秒内直接切图，风速控件暂时移除。WE 属性中的手动场景优先级更高；联动测试时请保持两项为“自动”。
- 模拟只改变壁纸桥接输出，主界面的天气、系统时间、日历提醒和真实天气缓存保持不变。无天气 API 配置也可以测试。关闭模拟恢复真实数据；关闭天气联动会清空壁纸天气与模拟时刻，继续使用本机时间。
- 模拟设置仅保存在此设备。BZ Hub 关闭或桥接中断超过 30 秒后，壁纸恢复本地时间，保留最后一次天气。

## 状态规则

- 05:00–08:00：清晨
- 08:00–17:00：晴天
- 17:00–20:00：黄昏
- 20:00–05:00：夜晚
- 和风天气代码 3xx：雨景（冻雨仍归雨）；4xx：雪景；5xx 或雾/霾/沙尘文字：雾景。阴天、多云使用当前时段的图片，不强制变成浓雾。

到达时间边界直接切图；雨、雪、雾优先使用各自的背景，不再与时间背景混合或追加夜间染色。

## 环境声音

- 默认开启，音量为 25%。在 Wallpaper Engine 选中本壁纸后的右侧属性中，可关闭“环境声音”或调整“环境音量”（0–100，0 为静音）。导入后若没有这两项，按上方更新说明添加属性：`ambientsound` 为勾选框、默认开启；`ambientvolume` 为整数滑块、范围 0–100、默认 25。
- 平常播放细微轻风与溪水声，叠加稀疏的水泡声；雪天整体更轻。轻风仅是声音，不会恢复已移除的风动画。
- 下雨时自动加入雨声：随现有天气分级与降水量，逐步增加雨滴密度、雨声亮度和低频水声；溪水退到背景。天气切换时声音用数秒渐变，画面仍然直接切图。雷阵雨使用对应强度的雨声，本版未加突然的雷声。
- BZ Hub 的模拟天气同样驱动声音，无需另设模拟音频；不改变主页面真实天气。暂停壁纸、页面隐藏、关闭声音或音量为 0 时，淡出并暂停音频处理；恢复后继续播放。
- 声音由本地 Web Audio 合成，不是自然录音，不下载音频、不调用生成服务、不消耗生成或天气 API 额度。噪声缓冲只在首次播放时生成，之后循环使用。
- 普通浏览器预览可能需要点击页面一次才能播放。WE 中没有声音时，请检查本壁纸的声音开关、音量及 WE/Windows 音频输出设置。

属性接口参考：[Wallpaper Engine 用户属性](https://docs.wallpaperengine.io/en/web/customization/properties.html)。

## 验证

仓库根目录运行 `node wallpaper-engine/check.mjs` 检查单图选择、降水分级、模拟隔离、关闭恢复和七张素材尺寸。运行 `node wallpaper-engine/check-browser.mjs` 进行 Edge 浏览器渲染与设置页验证（需要 Playwright；可用第一个参数提供本地模块路径）。截图写入上一级 `qa/`。

接口依据：[Wallpaper Engine 回调](https://docs.wallpaperengine.io/en/web/api/propertylistener.html)、[全局帧率](https://docs.wallpaperengine.io/en/web/performance/fps.html)、[和风天气代码](https://dev.qweather.com/en/docs/resource/icons/)。

风景图片是本项目的本地素材，不依赖网络加载；只有 BZ Hub 的本机天气桥接使用 localhost。
